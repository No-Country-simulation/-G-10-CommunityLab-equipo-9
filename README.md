# 🎓 InsightEdu Lab

> **Equipo:** G10-LATAM-equipo 9 | **Líder:** Gonzalo Costela  
> **Ecosistema:** No Country Simulation  

**InsightEdu Lab** es un motor inteligente impulsado por una arquitectura **Multi-Agente orquestada con LangGraph** que transforma el historial de chat de comunidades educativas digitales (Discord, Slack, Telegram) en un activo estratégico B2B.

---

### 🚀 Propuesta de Valor
* 📉 **Retención Estudiantil:** Automatiza el triaje de preguntas frecuentes (FAQ) y analiza el clima de satisfacción/frustración para mitigar la deserción.
* 📣 **Crecimiento Orgánico:** Identifica hitos y casos de éxito reales para redactar automáticamente copys persuasivos (LinkedIn/Comunidad), convirtiendo el UGC (User Generated Content) en la principal herramienta de conversión.

---

### 🛠️ Tech Stack & Arquitectura
* **Orquestación AI:** LangGraph (Multi-Agent System)
* **Frontend / Dashboard:** Streamlit (Human-In-The-Loop Validation)
* **Almacenamiento Cloud:** OCI Object Storage (Oracle Cloud Infrastructure) & Vector DB (RAG Search)
* **Ingesta de Datos:** Logs estructurados en JSON / CSV
